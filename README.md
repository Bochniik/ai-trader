# Orion Trader

An AI-powered paper trading platform.

## Stack

Frontend
- React
- Vite

Backend
- FastAPI

Charts
- lightweight-charts

Data
- Yahoo Finance

---

## Run Backend

cd backend

python -m uvicorn app.main:app --reload

---

## Run Frontend

cd frontend

npm install

npm run dev
